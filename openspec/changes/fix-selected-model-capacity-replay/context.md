Lifecycle metadata does not prove model output, but forwarding a numeric sequence binds the client to that upstream generation. Buffer those direct WebSocket frames and discard them when staging a replacement. Unsequenced bridge lifecycles retain their existing public identity; classification must still use the replacement generation's raw ID.

For example, created(0), in_progress(1), capacity failure can be replaced before delivery. An output item or terminal billed output cannot. A quota error mentioning capacity retains quota handling.

Verification uses existing tests only, as requested. Existing assertions that require capacity errors to surface or sequenced preludes to be delivered immediately describe the old behavior and must be reported separately if they fail.
